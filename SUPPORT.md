# Support

Read the [README](README.md), [development guide](docs/DEVELOPMENT.md) and
[service documentation](https://docs.cbgpu.com). For local setup problems, include
the command, version, operating system and sanitized error in a GitHub issue.
For school-account and equipment access, contact the school's service operators;
public issues are not an account-verification channel. Do not post credentials
or personal records. Maintenance and support are best effort.
