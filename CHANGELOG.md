# Changelog

This file tracks CBGPU changes. `backend/CHANGELOG.md` is the upstream
self-hosted Supabase changelog and is not the application's release history.

## 0.1.0 — 2026-11-04

- Add an isolated local demo with synthetic authentication, EduSet and GPU data.
- Add contributor documentation, issue/PR forms and a private security report policy.
- Add web, native-policy, Python and browser checks on GitHub Actions.
- Add tagged source releases, optional signed Android releases and SHA-256 manifests.
- Add school-specific configuration tooling and deployment guidance.
- Add dependency update automation and a third-party component inventory.

## Source baseline — 2026-11-04

- Publish the current web, mobile, self-hosted backend and operator services.
- Document the platform in English with screenshots of the running sites.
- Apply Apache-2.0 to original code while preserving separate component licenses.
- Include Android 1.0.7 (build 8), with the official EduSet login bridge.

The baseline is not an independently reproduced installation or a device-certification
claim. See the README's tests and status section for verification limits.
